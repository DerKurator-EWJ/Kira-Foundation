# KIRA FOUNDATION v0.24 – Bestand

Neue Funktion **Bestand**: Unterscheidet vorläufig zwischen **Teil von**, **verbunden mit** und **offen** anhand wiederholter gemeinsamer Bewegung und beobachteter Trennung. Die Unterscheidung gilt für beliebige Kennungen, nicht nur Bildobjekte.

## Start
- `START_BESTAND.bat` zeigt eine Figur, einen Arm und einen abnehmbaren Hut.
- `TEST_ALL.bat` führt die gesamte Testsuite aus.
- Die Startdateien früherer Versionen bleiben erhalten.

## Grenzen
Die Demo verwendet **vorgegebene** Beobachtungen und Bewegungsbelege. Es gibt noch keine automatische Bewegungserkennung, keine echte physikalische Teil-Erkennung und keine Integration in den dauerhaften Inquiry-Speicher. Die Kategorie `teil` ist eine **revidierbare Vermutung**: Auch dauerhaft gekoppelte Dinge können unabhängig sein. Beobachtete Trennung führt zur Revision; das Verlaufstagebuch hält sie fest.
